The dashboard shows "Guild <id>" for the guild. `apps/server/src/routes/me.ts` calls `ensureGuild(db, guildId, \`Guild ${guildId}\`)` and nothing ever stores the real name.
Fix: (a) in me.ts use the guild name the Discord OAuth guild list already gives (the guild objects there have `name`) when creating/refreshing the row; (b) `packages/discord/src/gateway.ts` stores the real name on `clientReady` (cached guilds), `guildCreate` and `guildUpdate`, only for allowed guilds; (c) the db helper in `packages/db/src/queries/guilds.ts` updates the name when it changed, and never overwrites a real name with the "Guild <id>" placeholder.
Tests: new `apps/server/test/me.test.ts` (name from OAuth list wins over placeholder), new `packages/discord/test/gateway-guild-name.test.ts` (guildUpdate renames), `packages/db/test/guilds.test.ts` (placeholder never overwrites a real name).
