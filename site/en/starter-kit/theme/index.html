Colour tokens of this preset

A preset changes colours only. Type sizes, radius and spacing stay the same in all three. The table reads the values from the screen above as it is now.

TokenColourValue

Use it on your server

  • Set it in server.cfg with setr (not set: the client has to read it), then players reconnect.
  • Any value other than these three names falls back to asphalt.
  • When aeterna_theme points at your own stylesheet, the kit sets no preset and your file wins.
  • aeterna_loading runs before any script, so it cannot read convars. Set its preset in its own html/config.json.
