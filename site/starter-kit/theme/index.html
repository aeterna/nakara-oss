ค่าสีของธีมนี้

ใช้กับเซิร์ฟของคุณ

  • ตั้งใน server.cfg ด้วย setr (ไม่ใช่ set เพราะฝั่งผู้เล่นต้องอ่านได้) แล้วผู้เล่นเชื่อมต่อใหม่
  • ค่าอื่นนอกจาก 3 ชื่อนี้ ชุดจะใช้ asphalt
  • ถ้าตั้ง aeterna_theme ไปที่ไฟล์ของคุณเอง ชุดจะไม่ใช้ธีมสำเร็จรูป ไฟล์ของคุณชนะ
  • aeterna_loading ทำงานก่อน script ทุกตัว จึงอ่าน convar ไม่ได้ ตั้งธีมของหน้าโหลดใน html/config.json ของมันเอง
