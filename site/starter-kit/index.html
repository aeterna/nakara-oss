AETERNA Starter Kit

ชุดพื้นฐาน 7 ตัวสำหรับเปิดเซิร์ฟ FiveM ของคุณเอง ใช้ตัวเดียวหรือทั้งชุดก็ได้

มีอะไรบ้าง

  • aeterna_core: ฐานร่วมสำหรับ focus ภาษา เวลา และที่เก็บข้อมูลฝั่งผู้เล่น
  • aeterna_uikit: panel, confirm, input, progress, skill check และเมนู
  • aeterna_notify: toast ประกาศ และข้อความต้อนรับ
  • aeterna_layout: ให้ผู้เล่นแต่ละคนลากและย่อขยาย HUD ได้ รวมถึงมินิแมปของเกม
  • aeterna_hudkit: แถบสถานะ แผงรถ ชื่อถนน และมินิแมป
  • aeterna_phonekit: โทรศัพท์พร้อมแอปในตัว 4 แอป และ API สำหรับเพิ่มแอปเอง
  • aeterna_invkit: stash ส่วนตัวและการใช้ไอเทมแบบมีเวลา บน ox_inventory

ติดตั้ง

ดาวน์โหลด zip แตกลง resources/[aeterna_kit]/ แล้วเพิ่มบรรทัดนี้ต่อจาก framework:

# server.cfg
setr aeterna_locale "th"
ensure aeterna_core
ensure aeterna_uikit
ensure aeterna_notify
ensure aeterna_layout
ensure aeterna_hudkit
ensure aeterna_phonekit
ensure aeterna_invkit

ทุกแพ็กเกจไม่ตั้งปุ่มเริ่มต้น ผู้เล่นตั้งเองได้ที่ Settings → Key Bindings → FiveM

ทดสอบกับ

FXServer Enhanced, game build 3788 กับ qbx_core 1.23.0, ox_lib 3.30.6, oxmysql 2.14.3 และ ox_inventory 2.44.0 เวอร์ชันอื่นยังไม่ได้ทดสอบ

หน้าตาเป็นของเซิร์ฟคุณ

ธีมเริ่มต้นตั้งใจให้เรียบ ตั้ง convar aeterna_theme ไปที่ไฟล์ของคุณเพื่อเปลี่ยนสี ความมน และฟอนต์ได้ทุกหน้าจอ ทุก release สร้างใน CI และมี provenance attestation ให้ตรวจก่อนติดตั้ง
