🏗️ Trust Architecture

โค้ดหนึ่งชิ้นผ่านอะไรบ้าง กว่าจะถึง server ของคุณ

กล่องสีส้มประกาศสิทธิ์ตรงกับโค้ด จึงผ่านทุกด่านไปถึงเครื่องคุณ กล่องสีเทาเรียก HTTP ที่ไม่ได้ประกาศ เลยถูกหยุดที่ด่านแรก ด่านที่สองและสามเราทำใน CI ด่านสุดท้ายคุณทำซ้ำเองได้

ประกาศสิทธิ์ตรงกับโค้ด: ผ่าน PR gate ได้ตรา attestation ใน release ตรวจซ้ำสามคำสั่งแล้ว ensure เรียก HTTP ที่ไม่ได้ประกาศ: devkit safety หยุดไว้ PR ล้ม ไม่มี release

ข้อจำกัด

สิ่งที่ scanner จับไม่ได้

scanner บอกได้ว่าโค้ดใช้แค่สิ่งที่ประกาศไว้ แต่บอกไม่ได้ว่าใช้อย่างสุจริตหรือเปล่า

logic bomb ใน API ที่ได้รับอนุญาตresource ที่ประกาศ db.tables: ["players"] ลบทุกแถวในวันใดวันหนึ่งได้
การเรียก export ของ resource อื่นexports.some_admin:giveAdmin(src) ดูเหมือนการเรียก export ทั่วไป
server ที่เชื่อ clientevent ที่ให้ของกับใครก็ได้ที่ขอ ประกาศครบ จำกัดอัตราแล้ว ก็ยังเป็นช่องโหว่
ค่าที่ประกอบตอน runtimeรายงานว่าเจอ แต่ไม่ได้ตามว่าค่าจริงคืออะไร

ยังต้องมีคนอ่านโค้ด

ใช้ฟรีไหม

สคริปต์ที่ซื้อมาและไม่มี oss.json ตรวจได้ไหม

ได้ ตั้ง requireManifest เป็น false ในไฟล์ .fivem-devkit.json แล้วเครื่องมือจะสแกนหาโค้ดอันตราย เช่น dynamic-load, host-exec, secret-convar โดยไม่ต้องมี oss.json

ผลสแกนไม่เจออะไร แปลว่าไม่มีปัญหาไหม

ไม่ ดูหัวข้อสิ่งที่ scanner จับไม่ได้ เครื่องมือหาแบบแผนที่รู้จัก และไม่แทนการอ่านโค้ด

ดาวน์โหลด resource ที่ไหน

หน้า Releases บน GitHub เท่านั้น ไฟล์ release build ใน CI และมี provenance attestation กับ SHA256SUMS ให้ตรวจ ส่วน ZIP ของ repo มีเทสต์และเครื่องมือที่ server ไม่ต้องใช้
