# AETERNA Starter Kit

ชุดพื้นฐาน 7 ตัวสำหรับเปิดเซิร์ฟ FiveM ของตัวเอง ใช้แยกทีละตัวหรือลงทั้งชุดก็ได้ · Seven base resources for running your own FiveM server. Use one or use them all.

| Resource | ไทย | English |
| --- | --- | --- |
| `aeterna_core` | ฐานร่วม: focus, ภาษา, เวลา, ที่เก็บข้อมูล | Shared base: focus, locale, time, storage |
| `aeterna_uikit` | panel, confirm, input, progress, skill check, เมนู | Panels, prompts, progress, skill check, menu |
| `aeterna_notify` | toast, ประกาศ, ข้อความต้อนรับ | Toasts, announcements, message of the day |
| `aeterna_layout` | ให้ผู้เล่นลากและย่อขยาย UI | Lets players move and scale the UI |
| `aeterna_hudkit` | แถบสถานะ, รถ, ถนน, มินิแมป | Status bars, vehicle, street, minimap |
| `aeterna_phonekit` | โทรศัพท์และ API ให้เพิ่มแอป | Phone shell and an app API |
| `aeterna_invkit` | stash ส่วนตัวและการใช้ไอเทมบน `ox_inventory` | Personal stash and item use on `ox_inventory` |

1. ดาวน์โหลด zip จาก [Releases](https://github.com/aeterna/nakara-oss/releases?q=aeterna_) แล้วแตกลง `resources/[aeterna_kit]/` · Download each zip and unpack it into `resources/[aeterna_kit]/`.
2. คัดลอก [`resources.cfg`](resources.cfg) ลง `server.cfg` · Copy [`resources.cfg`](resources.cfg) into `server.cfg`.
3. รีสตาร์ตเซิร์ฟ แล้วให้ผู้เล่นตั้งปุ่มใน Settings → Key Bindings → FiveM · Restart, then bind keys in Settings → Key Bindings → FiveM.
