# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment. Report problems privately to the
maintainer via a [private security advisory](https://github.com/aeterna/nakara-oss/security/advisories/new)
marked "conduct" or by email listed on the maintainer's GitHub profile.
